# Abstract

為什麼人們會使用筆記軟體？筆記軟體被視為能因應資訊過載，提升使用者的工作／學習效率的工具；但隨著越來越多「工作流」和套件伴隨著筆記軟體盛行而開發，關於筆記軟體如何回應並解決使用者面臨的問題卻較少被人所關注。凸顯在工具開發、使用，以及使用者如何應用之間存在未被釐清的關節。對此本文指出應當從：(1) 使用者如何接受外部資訊，使之成為個人能夠處理的信號（signal）；(2) 使用者如何打造個人資料庫（vault），藉以解決信號帶來的課題；以及 (3) 個人資料庫的機制對使用者和信號的影響是什麼；等三個視角進行分析，從而探討為什麼筆記軟體最終成為個人工作模式的核心。

本文以黑耀石軟體（ Obsidian）的使用者以及個人資料庫為研究對象，分析軟體使用者及其創造物之間如何進行「人–機協作」。

本研究預期「人–機協作」會體現在三個層面：(1) 資訊來源與形式的完整程度與傳遞速度會影響使用者在多大程度上依賴筆記軟體將其編碼成可被處理的信號；(2) 問題解決方式的複雜程度與細緻程度會影響使用者在建構個人資料庫的時候採納筆記軟體的設計，進而加深依賴；(3) 「人–機協作」的過程中筆記軟體以及個人資料庫將反向塑造使用者詮釋信號（input）、建構問題（output）的基礎，使得使用者及筆記軟體之間呈現出互相「再創」（inter-re-create）的成果。

對此，本文認為「人–機協作」呈現出筆記軟體實質上是一「心智勞動」的過程及產物；因此應當回到透過筆記軟體如何具現、再現人們心智勞動的基礎上進行推廣。
